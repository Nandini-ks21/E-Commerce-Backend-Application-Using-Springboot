**Project Overview**

E-Shop E9 is a full-featured E-Commerce backend application developed using Spring Boot and Java. The project is designed using a layered architecture pattern to provide scalability, maintainability, and secure REST API communication.

The system allows users to register, authenticate, manage products, and perform shopping-related operations through secure APIs using JWT authentication.

This project demonstrates real-world backend development concepts such as:

REST API Development
JWT Authentication & Authorization
Spring Security
Layered Architecture
Exception Handling
DTO Mapping
Database Integration using JPA/Hibernate
Redis Caching
Maven Project Management

**Security Implementation**

The project uses Spring Security with JWT authentication.

Security Flow
User logs in with credentials.
JWT token is generated.
Client sends token in Authorization header.
JWT filter validates token.
Authorized requests access secured APIs.
